The three S1s

fix before broad launch
1S1Security · Billing

Account deletion clears the Stripe mapping but never cancels the subscription

Evidenceauth.js:256-262 deleteAccount() calls only store.deleteAccountData(); db.js:489-495 blanks stripe_customer_id with no Stripe API call. Cancellation exists only via the user-driven Billing Portal, never on delete. Email is tombstoned, so the reconcile email-fallback can't match either. Confirmed.
ImpactA premium user who deletes their account keeps being charged with no in-app record to cancel against, and Stripe retains their customer object — direct financial harm and a contradiction of the "delete within 30 days" promise in privacy.html:192.
FixBefore blanking stripe_customer_id, best-effort list active subscriptions and stripe.subscriptions.cancel. Guard so a Stripe outage never blocks local deletion; log failures for retry.
2S1SecurityLive-verified

Admin dashboard transmits ADMIN_KEY as a URL query parameter

EvidenceThe live /admin.html serves JS building fetch('/api/admin/...?key='+getKey()). Gating works (unauth /api/admin/stats → 403, verified) but the key travels in the URL. admin.html already builds a headers() object it could route the key through.
ImpactThe high-value key lands in Railway/edge access logs, proxy/CDN logs, and browser history. One leaked log line grants full admin-dashboard read access — user enumeration, emails, geo. Credentials-in-URL is an OWASP-flagged anti-pattern.
FixSend the key in an Authorization/X-Admin-Key header and drop all ?key= usage; confirm access logs don't retain query strings in the interim.
3S1Legal · Compliance

Privacy policy names the wrong subprocessors and omits the real ones

Evidenceprivacy.html lists "Vercel" (DB), "cPanel" (email) and "Vercel Web Analytics" — but the API + SQLite run on Railway, email sends via Resend, analytics is first-party, and litestream.yml replicates the full DB (emails, pw_hash, geo) to Cloudflare R2, an undisclosed backup subprocessor. Confirmed.
ImpactGDPR Art.13/28 and CCPA/CPRA require accurate recipient disclosure. The list is both over- and under-inclusive, breaking any DPA/SCC chain on first audit or complaint.
FixRewrite privacy §5.1 to Railway, Resend, Cloudflare R2, Stripe (+ LibreTranslate if enabled); remove the false claims; confirm signed DPAs.
